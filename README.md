NBA Salary and Performance Analysis

This project presents a descriptive analysis of player salaries and performance for the Golden State Warriors across the 2022 and 2023 NBA seasons.

Objective

The main objective is to identify patterns and relationships between player salaries, playing time, and on-court performance using a descriptive statistical approach.

The analysis focuses on understanding how financial investment relates to player productivity and efficiency.

Dataset

The dataset contains preprocessed NBA player statistics, including:

- Salary (USD)
- Points
- Assists
- Rebounds
- Total Minutes Played

Analysis Performed

The project includes the following analyses:

- Identification of players in each season  
- Salary distribution analysis (mean, median, standard deviation, boxplots)  
- Performance analysis (points, assists, rebounds, minutes played)  
- Comparison between seasons (2022 vs 2023)  
- Scatter plots:
  - Salary vs Points  
  - Minutes vs Points  
  - Salary vs Assists/Rebounds  
- Efficiency metrics:
  - Cost per Point  
  - Cost per Minute  
- Outlier detection using boxplots  
- Identification of atypical player profiles  

Key Insights

- Salary distribution is highly skewed, with star players acting as outliers  
- Higher playing time generally leads to higher production  
- Salary does not always correlate directly with performance  
- Some players show high efficiency (low cost per point/minute), while others present poor cost-benefit ratios  
- Significant variation exists in player efficiency across the roster
