NBA Salary and Performance Analysis

This project presents a descriptive analysis of player salaries and performance for the Golden State Warriors across two consecutive NBA seasons.

Objective

The main goal is to investigate patterns and differences in player performance and salaries between the two seasons, using a descriptive statistical approach.

Dataset

The dataset used contains preprocessed NBA player statistics, including:

- Salary (USD)
- Points
- Assists
- Rebounds
- Total minutes played

Analysis Performed

The analysis includes:

- Identification of players in each season
- Salary distribution analysis (mean, median, boxplot)
- Performance indicators analysis (points, assists, rebounds, minutes)
- Comparison between seasons
- Scatter plots (salary vs performance)
- Cost per point calculation (efficiency analysis)
- Identification of outliers and atypical player profiles

Key Insights

- Changes in average salary between seasons
- Differences in performance metrics
- Identification of players with high and low cost-effectiveness
- Presence of salary concentration among key players

Technologies Used

- Python
- Pandas
- Matplotlib
- Google Colab
